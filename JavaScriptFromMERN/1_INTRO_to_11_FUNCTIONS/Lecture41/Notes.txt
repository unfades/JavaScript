In JS functions are first class citizens

means we can store them in variables. pass them as argument to other functions.
return them from other functions.

var a = parseInt(prompt("Enter a no: "));
OR
var str = prompt("Enter a no:");
var a = parseInt(str);

In simple terms we can treat functions like values.

IMPORTANT BUILT IN FUNCTIONS 

setInterval(function_name, time_period);
