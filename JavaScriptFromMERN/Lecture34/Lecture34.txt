WHAT IS NULL?
-------------

It is a value that is assigned by a programmer to indicate that the variable
currently has no value but will be assigned later.


In simple words, null means intentional absence of the value.

Example var age = null;

age = 19;

difference bw null and undefined

null is an assigned val, undefined shouldnt be assigned.

nulls an object, undefined is a type.
because JS is backwards compatible.
null indicates the absence of value for a variable.
undefined indicates the absence of the variable itself.

null is converted to 0 while performing primitve operations.
undefined is converted to NaN while performing primitive operations.
