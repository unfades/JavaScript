To work with Form we need to access it in our
JS code

Apart from using getElementById(). JS allows
us to access a Form object in 2 more ways:
1. Using the querySelector() method
2. Using the name property


important in FORMS in HTML

we have to 
1 using its name attribute
or 
2 using its particular elements property

let x = document.querySelector("input");
x.value refers to the text being inputted
inside the textbox.
