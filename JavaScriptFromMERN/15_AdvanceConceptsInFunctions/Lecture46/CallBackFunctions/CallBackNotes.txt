another function, then this technique in JS is called
as CALLBACK...

In JS's eyes, the name of a function is equivalent to it's body.

when we pass a function as arg to another function,
then it is called a callback function and the function
that takes another function as a parameter is called a
HIGHER ORDER FUNCTION

Remember? functions in JS are first class citizens

They can be stored in a variable - anonymous functions

Like variables, they can be passed as arguments to
other functions - callbacks

and like variables, they can be returned from a function

=========================================================
General Syntax:

<function1>(<somearg>,<function2>);
see explanation in the slides

now
suppose we got a function
function multiply(a,b){
    let x = a*b;
    console.log(x);
}

multiply(2,3); //6 is the output

function checkeveodd(n){
   if (n%2===0) console.log("even");
   else console.log("odd");

what we want to do is pass checkeveodd as an arg
into multiply, and be able to call checkeven odd
from multiply

function multiply(a,b,p){
    let x = a*b;
    console.log(x);
    p(x);
}

multiply(2,3,checkevenodd);
meaning checkevenodd is called inside the function
multiply by p(x)...
