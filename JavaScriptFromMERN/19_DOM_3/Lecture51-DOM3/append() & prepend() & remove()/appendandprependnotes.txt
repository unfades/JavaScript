To add a child element we can also use append() and prepend() methods.

STEPS:

1. obtain a reference to the parent element.
2. call the append() or prepend() methods using the parent element, passing the
child element to be added as an argument


append() appendChild() difference

append() allows us to also append DOM String objects, where appendChild() only accepts Node
objects.

append() can append nodes and strings together, where appendChild() can only append one node.

div.append("Hello"); works, added to the last of the div.

div.appendChild("Hello"); doesn't work
