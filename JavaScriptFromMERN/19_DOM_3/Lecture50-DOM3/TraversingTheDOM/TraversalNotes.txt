So we don't want a mixture of text nodes and element nodes.

DOM Properties have this drawback.

Although we can select HTML elements using DOM properties but these
properties also conside ENTER and TAB as the child nodes of a node.

So to overcome this problem, modern browsers support their alternative
properties which only consider HTML elements and ignores text nodes.
