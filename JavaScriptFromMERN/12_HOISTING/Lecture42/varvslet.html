var and let are different in 4 ways...

1. Scope
2. Redeclaration
3. Window object
4. Using before declaring

When you declare with var, it's global
When you declare with let, it's within the Scope of it's block.
 Example:
for (var i = 1; i <= 3; i++) {
console.log(i);
}
console.log(i);
Output:
1
2
3
4
Example:
for(let i=1; i <=3;i++){
console.log(i);
}
console.log(i);
Output:
1
2
3
Uncaught ReferenceError: i is not defined

You can redeclare var, cannot redeclare let

ex: var one = "yuh";
var one = "noh";

let two = "yuh";
let two = "noh"; //error: x is already defined

The Window Object
a variable declared with var becomes the property of the window object
but a variable declared with let does not become the property of the
window object...
Example:
var x=10;
let y=20;
console.log(window.x);
console.log(window.y);
Both are global, but x is a property of the window object, y is not

Output:
10
undefined
